4. TLS/SSL:
   cert-manager ClusterIssuer "{{ .Values.certManager.issuerName }}" has been created.

   Prerequisites:
     cert-manager must be installed BEFORE deploying this chart:
       kubectl apply -f https://github.com/cert-manager/cert-manager/releases/latest/download/cert-manager.yaml

   IMPORTANT: The solver ingressClassName in certManager.solvers MUST match
   ingress.className (currently "{{ .Values.ingress.className }}"). If they differ,
   the ACME HTTP-01 challenge will time out and no certificate will be issued.

   To enable TLS on your ingress, add to your values:
     ingress:
       annotations:
         cert-manager.io/cluster-issuer: {{ .Values.certManager.issuerName }}
       tls:
         - secretName: threadql-tls
           hosts:
             - {{ (index .Values.ingress.hosts 0).host }}

   Debugging TLS issues:
     kubectl get certificate -A
     kubectl get certificaterequest -A
     kubectl get order -A
     kubectl describe challenge -A
     kubectl logs -n cert-manager deploy/cert-manager
{{- end }}

Quick Start (k3s — already has Traefik):
  Set haproxy.enabled=false and ingress.className="" in your values.

Quick Start (DigitalOcean / AWS / GKE — no ingress controller):
  HAProxy Ingress is deployed by default and provisions a cloud LoadBalancer.
  Point your DNS A record to the LoadBalancer EXTERNAL-IP.
